🎯 Jeopardy — connect your devices

Each screen of the game gets its own address. Scan a QR code with a phone or iPad's camera, or type the address into the device's web browser. Every device must be on the same Wi-Fi as this computer.

Will these addresses be the same next time?

Usually, yes — feel free to bookmark them. The number version can occasionally change (for example after the router restarts), but this page always shows the current, correct address — so if a bookmark ever stops working, just start the server and look here again. The name version () stays the same even when the number changes; it works on Apple devices and most laptops, but some TVs only accept the number version.

If a device can't connect

Check it's on the same Wi-Fi (not cellular data, not a guest network). The first time you run the server, click Allow if the computer's firewall asks. If a TV browser adds https:// by itself, retype the address starting with http:// (no s). And keep the server window open the whole game — closing it disconnects everyone.
